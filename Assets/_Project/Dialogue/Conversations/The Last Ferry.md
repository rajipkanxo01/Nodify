# The Last Ferry

Open **Conversations > The Last Ferry**.

- `Test` is the traveler's coin count; `TestBoolena` is a ferry pass.
- Arrival resets both for repeatable play.
- Earn Fare adds two coins; Pay Fare subtracts three.
- Get Pass sets the Boolean true; Show Pass consumes it.
- Dock Choices demonstrates Integer < / >= and Boolean true / false conditions, plus an unconditional exit.
- Follow the return jumps to revisit choices after changing state.
- Sail Away and Walk Away demonstrate explicit endings.
- Arrival includes consecutive same-speaker lines; Sail Away includes multiline text.
- Named expressions and line tags are included. Expression variants reuse the existing portrait as a placeholder.
- Use **Frame All** for the whole graph or click a passage to read it.
